TrustLine on your phone

The Android app is the live site in a native shell — same reports, same desks, same response times. Because the app loads from the server, every fix that lands in the repo is the version you open next.

Download the Android app

The signed TrustLine .apk, about 3 MB.

Prefer not to install an APK?

Open the site in Chrome on your phone, then menu → Install app. You get a home-screen icon, a dark fullscreen view with nothing but the site, and an offline fallback — the same app, kept fresh from the same place.

After it's on your phone

  1. Open the app and sign in for your college under Staff sign-in.
  2. Track a report with its trace code, or follow a desk's response times.

Any Android that can run Chrome runs the app (Android 6.0+). If Chrome blocks the download, allow it in Settings → Apps → Chrome → Install unknown apps.
